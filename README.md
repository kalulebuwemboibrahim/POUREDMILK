# POUREDMILK — Final Website Build

Dark-only editorial cake information centre.

## Identity
- Circular cake emblem in the header
- Central hero cake photograph
- Dark chocolate/brown palette with cream typography and warm burnt-orange accents
- No light-theme toggle

## Pages
Home, Explore, Recipes, individual recipe pages, Learn, History, Tools, About.

## Run locally
Open `index.html` in a browser, or serve the folder with a local HTTP server.

## Note
The `assets/pouredmilk-logo.jpg` file is the supplied POUREDMILK cake photograph. CSS presents it as the circular brand emblem in the header and as the main hero image.


## Visual rule
Recipe cards use the supplied POUREDMILK cake photograph as circular imagery, so the Recipes page has an immediate visual element rather than empty thumbnail boxes.




## Author controls
Open `author-control.html` to preview, replace, crop and save the author portrait in the current browser. This is a browser-side control layer; secure server-side administration requires a hosting/backend setup.
